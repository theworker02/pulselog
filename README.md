# pulselog

Pulse and reshape log text streams with deterministic transforms.

**Site:** https://theworker02.github.io/pulselog/

## Install / run

```bash
git clone https://github.com/theworker02/pulselog.git
cd pulselog
node src/cli.js
node --test
```
